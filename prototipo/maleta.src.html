Maleta · protótipo

Clique num item para ver os detalhes; o botão direito abre o menu de ações. Espaço usa a cura selecionada; Delete tira o item selecionado. Shift+clique passa o item entre maleta e baú (e do armário direto para a maleta). Arraste para mover. R ou o botão direito giram enquanto arrasta. Solte uma erva em cima de outra para misturar, ou um anexo em cima da arma para equipar. Arraste para o baú (à direita) para guardar, ou para o armário para devolver.
